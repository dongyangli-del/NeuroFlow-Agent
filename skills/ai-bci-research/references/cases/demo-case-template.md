# Demo Case Template

Use this template for public, reusable demonstration cases. Do not include raw transcripts, private paths, unpublished sensitive details, credentials, participant information, or full experiment logs.

```markdown
## Case Title

Task:

Without NeuroFlow risk:

Workflow used:

Evidence checked:

Action taken:

Outcome:

Reusable lesson:

Files updated:
```

## Acceptance Criteria

- The case teaches a reusable behavior, not just a project fact.
- The evidence checked is explicit enough for a future agent to repeat the audit.
- The outcome is scoped to inspected artifacts.
- The reusable lesson can be routed back to a workflow, playbook, finding, or eval.
