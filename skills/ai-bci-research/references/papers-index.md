# Papers Index

This public file defines how paper memory should be organized without embedding personal publication strategy or unstable private metadata. Project-specific paper maps can be kept in a local gitignored private overlay.

## Public Entry Template

Use this structure when adding a paper that is safe to publish:

```text
### Paper Title

- Authors:
- Venue/status:
- Year:
- Public URL / DOI / arXiv:
- Related repository:
- Role in research trajectory:
- Core concepts:
- Datasets:
- Metrics:
- Caveats:
```

## Positioning Map Template

When positioning a new AI x BCI project, map it to one or more public axes:

- Neural decoding: brain signal -> category, stimulus, text, embedding, or behavior.
- Representation alignment: brain signal -> multimodal foundation-model space.
- Reconstruction/generation: brain signal or neural embedding -> image, text, audio, or stimulus.
- Closed-loop interaction: model action/stimulus -> neural response -> next action.
- Dataset/protocol contribution: acquisition, synchronization, annotation, splits, evaluation, and reuse.
- NeuroAI mechanism study: computational model, neural mechanism, and behavioral relevance.

## Citation Discipline

- Use exact title, author order, venue, and year only after checking the final source.
- Treat citation counts as unstable. Do not include them in papers unless the user explicitly asks and the source is verified.
- Separate public prior work from private in-progress work.
- Do not include unpublished results, reviewer strategy, private submission status, or lab-internal notes in this public index.
