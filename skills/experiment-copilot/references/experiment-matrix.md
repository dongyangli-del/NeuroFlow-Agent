# Experiment Matrix

## Priority Levels

| Level | Meaning |
|---|---|
| must-run | Needed to support the core claim |
| should-run | Needed to reduce likely reviewer objections |
| nice-to-have | Useful if time and compute remain |
| emergency | Fast rebuttal or sanity check |
