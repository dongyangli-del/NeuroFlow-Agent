# Figure Narrative

## Default Figure Arc

| Figure | Job |
|---|---|
| Figure 1 | Problem, method overview, and why the design matters. |
| Figure 2 | Main quantitative result under the primary protocol. |
| Figure 3 | Ablations showing which components matter. |
| Figure 4 | Generalization, robustness, error analysis, or limitation. |
| Figure 5 | Optional deployment, interpretability, or case study evidence. |

## Caption Rule

Each caption should state:

```markdown
What is shown:
Main takeaway:
Why it supports the claim:
Key limitation or protocol detail:
```

## Reviewer Risks

- Figure order follows implementation rather than argument.
- Main claim depends on qualitative examples only.
- Caption omits split, subject/session condition, baseline, or metric.
- Ablation figure does not isolate the claimed mechanism.
