# Rebuttal Plan

## Rebuttal Workflow

1. Separate factual reviewer misunderstandings from real evidence gaps.
2. Answer the strongest objection first.
3. Cite exact tables, figures, metrics, or new checks.
4. Narrow claims when evidence is insufficient.
5. Add fast experiments only when they directly address a blocking issue.

```markdown
Reviewer concern:

What we checked:
```
