# Benchmark Card Template

Use one card per benchmark candidate.

```markdown
Benchmark:
Verification status:
Signal modality:
Task:
Access route:
License or restrictions:
Data format:
Standard split:
Known baselines:
Metrics:
Adaptation work:
Leakage risks:
Compute/storage risk:
Use for:
Do not use for:
Next skill:
```

## Verification Status

Use one of:

- `verified from inspected source`
- `candidate from user-provided context`
- `needs verification`
- `not suitable`

Do not fill unknown subject counts, URLs, download commands, licenses, or leaderboard numbers from memory.
