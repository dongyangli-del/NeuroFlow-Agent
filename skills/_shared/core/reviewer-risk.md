# Reviewer Risk Checks

Use these checks before submission-facing writing, rebuttal, figure planning, or public benchmark claims.

## Blocking Risks

- Missing closest prior work or unsupported novelty.
- Weak or unfair baselines.
- Ambiguous split protocol or leakage risk.
- Metrics that do not match the stated claim.
- Missing ablations for the central mechanism.
- Missing uncertainty, subject/session variance, or statistical testing.
- Reproducibility gaps: data, weights, environment, commands, or expected outputs.

## Review Simulation Order

1. State the paper's strongest claim.
2. Name the evidence that directly supports it.
3. Identify the first experiment a skeptical reviewer would demand.
4. Check whether the current text overstates the evidence.
5. Propose the smallest experiment or edit that lowers risk.

## Rebuttal Discipline

- Answer factual misunderstandings with inspected evidence.
- Admit true limitations and narrow claims instead of defending unsupported breadth.
- Do not promise experiments unless they can be completed and reported precisely.
