# Privacy Policy

## Public Files Must Not Include

- Local absolute paths.
- Credentials, tokens, API keys, or private keys.
- Participant-identifying information.
- Raw human-subject notes or IRB-sensitive details.
- Unreleased results unless the user explicitly asks to store them publicly.
- Full transcripts or raw logs.

## Private Routing

Use ignored private overlays for sensitive memory:

- `.private/references/*.private.md`
- `skills/*/references/private/`

When uncertain, keep the memory out of public files and summarize only the reusable non-sensitive behavior.
