## Work Order

1. Establish the user goal and artifact.
2. Classify depth as shallow, standard, deep, or persistent.
3. Load only the relevant first reads.
4. Route to one primary specialist for shallow or standard tasks.
5. Route to a task chain for deep tasks.
6. Use supporting skills for mature methods, not duplicate domain judgment.
7. Validate against evidence, reviewer risk, reproducibility, and privacy constraints.
8. End with a memory candidate when the behavior should persist.
