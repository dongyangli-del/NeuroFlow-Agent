## Work Order

1. Establish the user goal and artifact.
2. Load only the relevant first reads.
3. Route to one primary specialist.
4. Use supporting skills for mature methods, not duplicate domain judgment.
5. Validate against evidence, reviewer risk, and privacy constraints.
6. End with a memory candidate when the behavior should persist.
