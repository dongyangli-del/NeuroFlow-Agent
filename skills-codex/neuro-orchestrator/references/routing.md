# Routing

## Single Entry Rule

Use `neuro-orchestrator` first. Specialist skills are optional modules selected by the orchestrator.

## Module Map

| Need | Optional module |
|---|---|
| AI x BCI validity, leakage, signal, safety, closed-loop guardrails | `ai-bci-research` |
| New research idea or hypothesis | `neuro-idea-finder` |
| Literature grounding or citation support | `paper-rag-plus` |
| Benchmark, dataset, split, metric, baseline, leakage audit | `eeg-benchmark-hunter` |
| Paper or repository reproduction | `repro-pack` |
| Continual, adaptive, personalized, or streaming BCI design | `continual-learning-designer` |
| Experiment matrix, ablation, control, statistics | `experiment-copilot` |
| Reviewer simulation or rebuttal risk | `reviewer-simulator` |
| Oral-level thesis, figure narrative, paper text | `oral-writer` |
| Durable session memory | `neuro-memory` |

## Depth Rules

| Depth | Rule |
|---|---|
| Shallow | One next check or scoped answer. |
| Standard | One artifact plus one evidence gate. |
| Deep | Multiple stages across literature, experiments, review, writing, or reproduction. |
| Persistent | Any depth plus a memory update decision. |
